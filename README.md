# Мир мебели

Статический сайт мебельного магазина. Для локального просмотра откройте `index.html` или запустите `python3 -m http.server 8000` и перейдите на `http://localhost:8000`.

Изображения интерьеров служат примером оформления. В каталоге представлена подборка товаров с arzanmebel.ru без цен; фотографии загружаются непосредственно с сайта-источника. Данные не синхронизируются автоматически, наличие требуется уточнять по телефону. Для полного каталога необходима выгрузка товаров. Формы заказа и приёма платежей нет.

## Автоматическая публикация

Workflow `.github/workflows/deploy.yml` публикует статические файлы при push в `main` или `arena/8fa9f243-mir`, а также вручную через Actions. Для публикации используется **обычный FTP без шифрования** по согласованию с владельцем: логин, пароль и файлы передаются открытым текстом. По возможности рекомендуется перейти на FTPS или SFTP. По умолчанию используется порт 21. Каталог сайта должен уже существовать и быть доступным для записи. Домен `mir.ezegames.ru` должен быть направлен на этот хостинг, а веб-сервер — настроен на указанный каталог. DNS, веб-сервер и HTTPS workflow не настраивает.

В GitHub: **Settings → Secrets and variables → Actions → New repository secret** добавьте:

- `FTP_SERVER` — имя FTP-сервера без протокола и порта.
- `FTP_USERNAME` — пользователь FTP.
- `FTP_PASSWORD` — пароль FTP.

Путь публикации `/` задан в `FTP_DIR` в workflow: это корень FTP-пользователя `mir`, который должен указывать на `/www/mir.ezegames.ru`. При изменении FTP-пользователя проверьте путь перед публикацией, чтобы не перезаписать другой сайт. При необходимости создайте repository variable `FTP_PORT` (по умолчанию 21). Не отправляйте пароли в чат и не добавляйте их в репозиторий. После настройки запустите workflow вручную или отправьте новый commit. Workflow обновляет только файлы сайта и не удаляет старые файлы на сервере.
