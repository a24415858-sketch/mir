# Мир мебели

Статический сайт мебельного магазина. Для локального просмотра откройте `index.html` или запустите `python3 -m http.server 8000` и перейдите на `http://localhost:8000`.

Изображения интерьеров служат примером оформления. В каталоге 580 товарных вариантов из предоставленных CSV и PDF arzanmebel.ru (кухня «Адель» и диваны исключены по просьбе владельца). Дата сбора указана в PDF как 12.11.2026. У 14 вариантов цена отсутствует в выгрузке; у части вариантов нет фотографий. Большинство фотографий — миниатюры из PDF с ограниченным разрешением; 23 подобранных оригинала загружаются с сайта-источника с запасной миниатюрой при наличии. Подробные описания в выгрузке отсутствуют: показаны названия и варианты без придуманных характеристик. Данные не синхронизируются автоматически; актуальные цены и наличие требуется уточнять по телефону. Состав и полнота каталога сайта-источника после выгрузки не проверены. Формы заказа и приёма платежей нет.

## Автоматическая публикация

Workflow `.github/workflows/deploy.yml` публикует статические файлы при push в `main` или `arena/8fa9f243-mir`, а также вручную через Actions. Для публикации используется **обычный FTP без шифрования** по согласованию с владельцем: логин, пароль и файлы передаются открытым текстом. По возможности рекомендуется перейти на FTPS или SFTP. По умолчанию используется порт 21. Каталог сайта должен уже существовать и быть доступным для записи. Домен `mir.ezegames.ru` должен быть направлен на этот хостинг, а веб-сервер — настроен на указанный каталог. DNS, веб-сервер и HTTPS workflow не настраивает.

В GitHub: **Settings → Secrets and variables → Actions → New repository secret** добавьте:

- `FTP_SERVER` — имя FTP-сервера без протокола и порта.
- `FTP_USERNAME` — пользователь FTP.
- `FTP_PASSWORD` — пароль FTP.

Путь публикации `/` задан в `FTP_DIR` в workflow: это корень FTP-пользователя `mir`, который должен указывать на `/www/mir.ezegames.ru`. При изменении FTP-пользователя проверьте путь перед публикацией, чтобы не перезаписать другой сайт. При необходимости создайте repository variable `FTP_PORT` (по умолчанию 21). Не отправляйте пароли в чат и не добавляйте их в репозиторий. После настройки запустите workflow вручную или отправьте новый commit. Workflow обновляет только файлы сайта и не удаляет старые файлы на сервере.

## Обновление каталога

Файл `data/catalog.js` и `assets/catalog/` подготовлены из предоставленных CSV и PDF скриптом `tools/import_catalog.py` (требуется Python и PyMuPDF):

```sh
python tools/import_catalog.py путь/к/catalog.csv путь/к/catalog.pdf
```

Сопоставление фотографий выполняется по URL и полному названию варианта, а при неоднозначности также по артикулу; неоднозначные совпадения пропускаются. Ссылки на подобранные оригиналы хранятся в `tools/highres_images.json` и привязаны к артикулам. Перед повторным импортом следует проверить, что формат и дата выгрузки не изменились, и обновить дату в тексте на странице. Скрипт не удаляет неиспользуемые старые миниатюры. Исходные CSV и PDF в репозиторий не включены. Публикация рекурсивно загружает файлы из `assets/` и `data/`, но старые файлы на сервере не удаляет.
